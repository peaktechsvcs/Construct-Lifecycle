CONSTRUCT LC — ENVIRONMENT, DEMO/TESTING, PRODUCTION & CUSTOMER BRANDING IMPLEMENTATION

You are working on the existing Construct Lifecycle application.

This is an existing application with a functioning first-version UI and project lifecycle experience. Do NOT rebuild the application from scratch.

The goal of this task is to establish a proper DEMO/TESTING environment and a clean PRODUCTION environment while preserving the existing application's functionality and visual design.

This task also extends the previously defined multi-tenant architecture and customer branding capability.

2. CRITICAL SAFETY REQUIREMENT
============================================================

DO NOT delete or overwrite the current production database until a safe migration/copy strategy has been established.

The current production application contains valuable demo/test data and must be preserved.

Before making environment changes:

1. Inspect the current deployment.
2. Inspect the current database.
3. Determine how environment variables and secrets are configured.
4. Determine how the current deployment connects to the database.
5. Determine whether the current production database can be cloned/exported.
6. Establish a backup.
7. Verify the backup.
8. Create the DEMO/TESTING environment from the current application/database state.
9. Only after the demo environment has been verified should the clean production environment be established.

If the current Replit deployment architecture does not support the desired separation exactly as described, do not improvise a destructive solution.

Instead, document the limitation and implement the safest equivalent architecture.
