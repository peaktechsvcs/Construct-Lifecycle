---
name: Construct Lifecycle design direction
description: Approved visual direction for Construct Lifecycle product surfaces.
---

Use a compact, project-centered operational UI with vivid blue primary actions,
navy navigation, amber attention accents, Inter UI typography, and DM Mono for
operational metadata. Reusable components should favor clear hierarchy, restrained
surfaces, and dense but readable layouts.

**Why:** The user approved the source-backed design-system pilot using this
direction without revisions.

**How to apply:** Keep future Construct Lifecycle components and artifacts
consistent with this visual language unless the user requests a new direction.
